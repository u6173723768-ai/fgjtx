# The GOD MENU

The GOD MENU is a client-side Fabric utility mod for Minecraft 1.21.11 and Java 21.

## Open the menu

Press **Right Shift** in-game. Press Right Shift or Escape to close it.

## Modules in this build

### Free
- Auto Sprint
- Auto Jump
- Fullbright
- Cursor Smoke
- Coordinates HUD
- FPS HUD
- Fall Height HUD

### Premium
- Chunk HUD
- Velocity HUD
- Direction HUD
- Clock HUD
- Ping HUD
- Watermark HUD
- Compact HUD

Premium-only modules are unlocked in the Premium JAR. Module settings are saved to `config/thegodmenu.properties`.

## Build

Run:

```sh
gradle --no-daemon clean build sourceZip
```

The build creates:
- `build/libs/The-God-menu-Free-1.21.11.jar`
- `build/libs/The-God-menu-Premium-1.21.11.jar`
- `build/distributions/TheGodMenu-Source.zip`

This build contains client-side quality-of-life and HUD features. It does not include anti-cheat bypasses.
